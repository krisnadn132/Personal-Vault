# Krisna's Vault

Enterprise-style offline financial management dashboard built using HTML, CSS, and JavaScript.

## Features

- Transaction management
- Budget planning
- Savings goals
- Wishlist tracker
- Subscription management
- Crypto portfolio tracking
- Financial analytics
- Dark/light mode
- Local JSON backup system
- LocalStorage persistence

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- LocalStorage API

## Project Structure

project/
- index.html
- css/
- js/
- assets/

## Deployment

Can be deployed directly using:

- GitHub Pages
- Netlify
- Vercel

## Security Notice

Current authentication is client-side only and should not be considered secure for production financial systems.
